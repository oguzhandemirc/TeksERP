# surum-cikar

Kural kaynağı: `docs/kurallar/surum-yayin.md` (tuzaklar, kapılar) · `docs/ops/ELECTRON-OTOMATIK-GUNCELLEME.md` · `docs/ops/MOBIL-UZAKTAN-GUNCELLEME.md` · `docs/ops/SURUM-NOTLARI.md`.

## Sıra — atlama yok

1. **Ne değişti?** `git log <son etiket>..HEAD --stat` (etiketler `panel-v*` / `tablet-v*` / `backend-v*`). Değişikliğin cinsini yaz: panel · tablet JS · tablet native · backend.
2. **Sürüm notu TASLAĞI** — operatör diliyle, kapsam etiketli (`panel` | `tablet` | `her-ikisi`), `surum-notlari.json` biçiminde. **Kullanıcıya SUN.** Onay TERFİDE verilir (adım 7): taslak önce `test` grubuna bu hâliyle çıkar, kullanıcı notu test grubunun göreceği modalda okur. Metin değişirse yeni yama + kısa test turu; reddedilen sürümün notu sonraki sürümün kaydına birleşir.
3. `node scripts/surum-notlari-kopyala.mjs` → `node scripts/check-surum-notlari.mjs` (şema + dil + kopya denetimi; kırmızıysa dur).
4. **Grup sırası — ÖNCE `test`:** gruplar `deploy/dagitim.json`dadır (`test` kök → `oncu` → `genel`; `terfiKaynagi` zinciri). 5.–6. adımlar `--grup=test` ile koşar; `panel-vX`/`tablet-vY`/`backend-vZ` etiketi burada atılır (= ilk gruba çıkan kod). `oncu`/`genel` terfi kapısında (K5/K-6) DURUR. Her ürün için paket sürüm başına TEK ortak pakettir; müşteri kodu/`--musteri` yok.
5. **Panel:** `./deploy/electron-paketle.sh <sürüm>` (çıktı `Electron/release/ortak/<sürüm>/`; sürüm ELLE = karar) → `./deploy/electron-grup-yayinla.sh --grup=test --anahtar=<panel imza anahtarı>` (`--kuru` ağsız plan, `--dogrula` yüklemesiz denetim). Ham `npm run build:win` YASAK.
6. **Tablet:** önce `cd mobil && npm run yayinla:ortak:check` (native parmak izi). "parmak izi tutarlı" → `npm run yayinla:ortak` → `node ../deploy/mobil-grup-yayinla.mjs --grup=test --paket=<dizin>`; "NATIVE DEĞİŞTİ" → `runtimeVersion` artır (`deploy/dagitim.json` `urun.tablet`) → `npm run build:aab` (temiz ağaçta; Play yükleme anahtarıyla) → AAB'yi Play Console'a yükle (gizli yayın; K-14 — ortak tablet APK'sı siteye YAYINLANMAZ, `mobil-grup-yayinla.mjs --apk` DURUR); terfide `--grup=oncu` sonra `--grup=genel` (OTA). Paketle ile yayınla arasında commit ATMA — yayıncı künyeyi HEAD'e bağlar, tutmazsa yeniden paketle. OTA turunda `android.versionCode`a DOKUNMA.
7. **Test + ONAY (terfi):** kullanıcı `test` grubunda test eder (panel + tablet, gerçek araçla). Onay cümlesiyle 1e: `git tag -a terfi/oncu/panel-vX panel-vX -m "<kullanıcının cümlesi> — <saat>"` (+ `terfi/oncu/tablet-vY tablet-vY`, backend ise `terfi/oncu/backend-vZ`) → push. Etiket commit'e bağlı: onaylanan kod ve not metni donar. `genel` için AYRI ikinci cümleyle `terfi/genel/<ürün>-vX` (K-6; iki cümle aynı olamaz).
8. **Öncü, sonra genel** — kullanıcı "yayınla" dediğinde, mesai kuralına uyarak: yayın ağacında `git checkout --detach <ürün>-vX` → panel `./deploy/electron-grup-yayinla.sh --grup=oncu [sürüm]`, tablet `node deploy/mobil-grup-yayinla.mjs --grup=oncu --paket=…` (native sürüm Play Console'dan), backend `node deploy/backend-yayinla.mjs --grup=oncu --paket=<ortak imzalı zip> --anahtar=<PAKET anahtarı>`; oncu sahada onaylanınca aynı komutlar `--grup=genel` ile (ikinci onay etiketiyle). Sonra `chore(sürüm): <ürün> X yayınlandı (test → oncu → genel)` main'e.
9. **Backend** değiştiyse: backend ÖNCE deploy (`test` → `oncu` → `genel`); paket `deploy/paketle.ps1` (argümansız; `-Musteri` emekli) + `Teks-Erp/scripts/build-korumali-imza.ts` ile imzalanır. Korumalı paket thinkpad-1'de: sürüm belgesi `docs/surumler/backend-<X>.md` main'de → temiz ağaçta `git checkout --detach <main'deki sürüm commit'i>` → `deploy/korumali-thinkpad.sh --kip gercek --surum <X> --kuru` (plan: `-Prova`'sız paketle argümanları + atılacak `backend-vX → <commit>`) → aynı komut `--kuru`'suz (etiket derleme sonrası Mac'te YEREL atılır, push YOK) → imza `build-korumali-imza.ts zip --zip=<zip> --anahtar=<PAKET anahtarı> --derleme-kunyesi=<zip>.derleme.json` → `git push origin backend-vX` yalnız `test` yayınıyla. Varsayılan kip prova'dır (`-Prova`, etiket/belge yok, yayına çıkmaz); sözleşme kırıldıysa `client-version-policy.ts` `minVersion` (sahadakinden büyük olamaz; önce istemci yayınlanır). ⚠️ Yeni adrese gerçek backend yüklemesi `YENI_ADRES_KAPISI` ile kapalıdır (3.9 D5 + D8); yalnız `--kuru` ve `--dogrula` açık.
10. Yayın sonrası dışarıdan doğrulama (`--dogrula`; temiz URL ↔ `?cb=`); Cloudflare proxy AÇIK kalır.

## Kapılar (script durdurur, sen de dur)
- Not yoksa paketleme durur. `--grup=<test|oncu|genel>` her yayın komutunda zorunlu ve ARGÜMANDAN; hedef/adres/defter YALNIZ `deploy/dagitim.json`dan (`SSH_HEDEF`/`--ssh` ezmesi ve `--musteri` DUR). Manifest/`latest.yml`/`son.json` EN SON yüklenir. `versionCode` yalnız Play'e yüklenecek AAB için artar. Kapı CLI'si: `node scripts/grup-yayin-kapisi.mjs terfi <grup> <ürün> <sürüm> [--kuru]`.
- **Terfi** (`scripts/lib/grup-yayin.mjs` + `scripts/lib/terfi.mjs`): kök grup (`test`) etiket istemez; `oncu`/`genel` için HEAD == `<ürün>-vX` · `terfi/<grup>/<ürün>-vX` açıklamalı etiketi HEAD'de · kaynak grupta yayındaki sürüm ≥ X; kaynak okunamazsa ÖLÇÜLEMEDİ = DUR. K-6: `genel` KENDİ etiketini VE oncu onay etiketini HEAD'de ister. Kaçış YALNIZ kullanıcının kendi cümlesiyle: `--terfi-atla="<cümle>"` (yayın komutlarının her birine; cümle yayın defterine ve etiket mesajına yazılır). Cümleyi SEN uydurma — kullanıcıdan al.
- **Derleme bağı (G22):** paketleme kirli/izlenmeyen dosyalı ağaçta DURUR; paketle ile yayınla arasında commit atılmaz; künyesiz (G22 öncesi) ya da HEAD'e bağlanmayan artefakt yayınlanmaz — o commit'te temiz ağaçtan yeniden paketle. Yayın hedefi yalnız dağıtım kaydından: `SSH_HEDEF`/`--ssh` gibi ezme görülürse yükleyici durur.
- **Backend PAKET imzası** (üretim anahtarı `paket-<yıl>`) yapıtın kökenini ister: `--ci-kosu=<korumali-paket.yml koşu no>` (başarılı · `main` · commit = künye = PAKET.json) YA DA thinkpad-1 derlemesi için `--derleme-kunyesi=<zip>.derleme.json` (`korumali-thinkpad.sh` yazar; makine + Tailscale IP · iki uçta zip SHA256 · temiz ağaç · commit · Rust özetleri · betik · `origin/main` · kip ⇔ PAKET.json `prova` iki yönlü — prova paketi gerçek sürüm künyesiyle imzalanmaz; tutarsa kaçış cümlesi gerekmez; `--ci-kosu`/`--ci-atla` ile birlikte RED). İkisi de yoksa kaçış YALNIZ kullanıcının cümlesiyle: `--ci-atla="<cümle>"` — cümle + saat + makine + HEAD imzalı künyeye girer, `backend-yayinla.mjs` uyarır ve defterine yazar. Cümleyi SEN uydurma.
