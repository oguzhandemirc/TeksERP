# KRİTİK YAZMA YOLLARI — Prompt §4.2 karşılıkları + Teks-Erp'e özgü yollar (aşama ① KEŞİF sentezi)

**Tarih:** 2026-08-28 · dal `adnansahin` · HEAD `ce8681d1` · Yazan: matris sentezleyicisi (salt-okunur; kaynak ağaca dokunulmadı).
**Girdi:** `audit/00-map/` altındaki 16 harita (K1a/K1b rota, K2a/K2b şema+DB, K3a/K3b tx+kilit, K4 yazma yolları, K5 yetki, K6 hata, K7a/K7b hesap, K8 scheduler, K9 entegrasyon, K10 değişmezler, K11 bekçi, K12 uzlaştırma) + `MATRIX.md` (varlık × yazma yolu). **Yeni ölçüm YAPILMADI**; her hücre haritanın satırına atıf taşır. Yargı yok — "② endişe hipotezi" sütunu ② denetçisinin sınayacağı sorudur.

**Sütun anahtarı:**

| Sütun | İçerik |
|---|---|
| **ID** | `KYY-NN` (Kritik Yazma Yolu); numara sabittir, sıralama önceliğe göredir |
| **Giriş noktası** | HTTP uç (metod + yol + kapı zinciri; `VT`=verifyToken, `P()`=requirePermission, `ANY()`=requireAnyPermission) → controller → servis fonksiyonu `dosya:satır` (K1a/K1b); dahili çağıranlar ayrıca |
| **Tx sınırı** | `$transaction` başlangıç/bitiş satırı, tx-ÖNCESİ / tx-DIŞI / tx-SONRASI adımlar, `withBarcodeRetry` (wBR) sarmalı mı, audit konumu (K3a/K3b) |
| **Kilit / claim** | edinim SIRASI ile: advisory NS (8021-8027, `A21`=8021 …), satır kilidi (`W` WO `touchWorkOrderTx` · `S` Sack `touchWarehouseSackTx` · `H` Shipment `touchShipmentPlannedTx` · `L` OrderLine `touchOrderLinesTx` · `K` barkod sayacı satırı · `Q` kilitsiz max+1 sayaç), **claim** = `updateMany WHERE {id, beklenen}` + `count`; **YOK** açıkça yazılır |
| **DB kısıtı** | unique / partial unique (predicate) / CHECK / trigger / FK (`C` cascade · `R` restrict · `SN` set null · `*` Prisma varsayılanı) / DEFERRABLE (K2a/K2b) |
| **Bekçi** | `scripts/test_*.ts`; `EŞZ ✓` = gerçek paralel yazma sondası, `EŞZ ✗` = yok (K11 §2/§4b) |
| **CTA** | check-then-act: tx dışında okunup tx içinde karara giren değerler (K3a §6, K3b §5) |
| **② endişe** | harfler A-L = `SINIR-OTESI-YONLENDIRME.md` alan alfabesi (A eşzamanlılık · B mükerrer/idempotency · C veri modeli · D tx sınırı · E iş kuralı · F API · G güvenlik · H performans · I hata/gözlem · J migration/kurtarma · K test · L kod kalitesi) |

Bir yol birden çok sınıfa dokunuyorsa birincil sınıfa yazıldı, diğerleri endişe sütununda harfle işaretli.
